# this is the quote service

# UNFILLED database microservice
if you want a clean database with nothing inside, just run `python quote_service.py`
This is the base program that allows the routes and database to be creatd.


# FILLED database microservice
if you want a databae with 100 quotes already inside, then first run `python generate_quotes.py`
Then, run `quote_service.py`.

This will allow it so that database will have 100 quotes already in the database.
